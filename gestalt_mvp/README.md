# Gestalt-MVP: Neuro-Symbolic Gesture Recognition System

## Overview

Gestalt is a mobile-first neuro-symbolic cognitive prosthesis for non-verbal users. 
It translates personalized hand gestures into spoken language using a deterministic 
DTW matcher gated by a symbolic confidence engine.

**This is Phase 0: a single-user feasibility study.**

### Core Hypothesis

> A deterministic DTW matcher operating on Z-axis-normalized MediaPipe hand trajectories 
> with a 20% Sakoe-Chiba band can discriminate a 10-class dynamic gesture vocabulary 
> for a single enrolled user under held-out session variation, achieving macro F1 > 0.85 
> AND open-set FAR < 5% simultaneously.

## Architecture

```
[ CAMERA (mounted, facing user) ]
         │
         ▼
[ MEDIAPIPE HANDS ]  →  21 landmarks × 30fps
         │
         ▼
[ PREPROCESSING & SEGMENTATION ]
    1. Translation / Scale / Z-Rotation normalization
    2. Velocity energy calculation
    3. REST → MOTION → REST boundary detection
         │
         ▼
[ DETERMINISTIC TRAJECTORY MATCHER ]
    DTW against enrolled exemplars (5-10 per class)
    Outputs: D1, D2, margin
         │
         ▼
[ COST-WEIGHTED THRESHOLD GATE ]
    ACCEPT / CLARIFY / REJECT
         │
         ▼
[ FINITE STATE MACHINE ]
    Gesture ID → Meaning Slot
    Handles CORRECTION state
    Handles SILENCE (hardwired, bypasses DTW)
         │
         ▼
[ DETERMINISTIC PHRASE TEMPLATES ]
    "I would like {OBJECT}, please."
         │
         ▼
[ TTS ACTUATOR ]  (Piper / Sherpa-ONNX)
```

## The 10-Gesture Vocabulary

| ID  | Name     | Motion Description                                    |
|-----|----------|-------------------------------------------------------|
| G1  | Water    | Chest → sharp arc to mouth → return to chest         |
| G2  | Help     | Both hands at waist, palms up, lift 6in → return     |
| G3  | Yes      | Closed fist, sharp double-nod (up-down-up) → return  |
| G4  | No       | Index+middle extended, horizontal snip → return      |
| G5  | Food     | Bunched fingertips, tap chin twice → return to lap   |
| G6  | Pain     | Flat hand, palm in, tap chest center twice → return  |
| G7  | Stop     | Flat hand, palm out, sharp forward push → return     |
| G8  | More     | Both flat hands, palms facing, clap once → return    |
| G9  | Wait     | Flat hand, palm down, slow horizontal circle → return|
| G10 | Bathroom | Flat hand "C" shape, tap lower abdomen twice → return|

## Usage

### Data Collection

```bash
cd data_collection

# Collect enrollment data (Sessions 1-2)
python collect.py --session 1 --gesture G1 --repetition 1 --condition normal
python collect.py --session 1 --gesture G1 --repetition 2 --condition normal
# ... repeat for all gestures and repetitions

# Collect calibration data (Session 3)
python collect.py --session 3 --gesture G1 --repetition 1 --condition normal
# ... 

# Collect test data (Sessions 4-5)
python collect.py --session 4 --gesture G1 --repetition 1 --condition normal
```

### Evaluation

```bash
cd evaluation

# Run locked evaluation
python evaluate.py --data-dir ../data_collection/data --results-dir results
```

## Evaluation Metrics

**Primary endpoint:** Macro F1 > 0.85 AND FAR < 5% simultaneously.

**Metrics reported:**
- 10×10 confusion matrix
- Macro F1, per-class precision/recall
- FAR = unknown trials accepted as any gesture / total unknown trials
- FRR = known gestures rejected / total known gestures
- Near-miss rejection rate (NEG-3)
- p95 segmentation latency
- p95 DTW computation time
- Session-level bootstrap confidence intervals

**Cost function:**
```
Cost = 10 × FP + 2 × FR + 0.5 × Clarifications
```

## Three-Way Data Split

| Sessions  | Role        | Rules                                    |
|-----------|-------------|------------------------------------------|
| 1-2       | Enrollment  | Build multi-exemplar library             |
| 3         | Calibration | Tune ALL thresholds. FREEZE. Never touch.|
| 4-5       | Locked Test | Run ONCE. Report metrics. Never modify.  |

Split by SESSION, never by frame.

## Absolute Rules (Phase 0)

1. Do NOT use Qwen, GPT, LLaMA, or any LLM
2. Do NOT use SmolVLM2 or any VLM
3. Do NOT use IMU data
4. Do NOT implement BDI - use deterministic FSM
5. Do NOT implement sleep mode consolidation
6. Do NOT implement emotion detection
7. Do NOT use FAISS - brute-force nearest-neighbor only
8. Do NOT tune thresholds on Sessions 4-5
9. Do NOT split data by frame - split by session
10. Do NOT include static-hold gestures
11. All parameters tuned on Session 3 are FROZEN before Session 4
12. Every decision must be logged to an audit trail (append-only JSONL)
